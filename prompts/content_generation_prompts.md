# Content Generation Prompts

## Overview
This file contains 15+ prompts designed and tested for content generation tasks across ChatGPT, Claude AI, and GitHub Copilot. Each prompt includes context, prompt text, expected output, and LLM used.

---

## Category 1: Professional Writing

### Prompt 1
**Context:** Writing a LinkedIn post about a data project
**Prompt:**
> "Write a professional LinkedIn post announcing my Bengaluru Traffic Analysis project. Include: project overview, tools used (Python, SQL, Power BI), key finding (43% speed reduction at Silk Board during peak hours), and a call to action. Keep it under 200 words with relevant emojis."

**LLM Tested:** ChatGPT, Claude AI
**Expected Output:** Engaging LinkedIn post
**Best Performer:** Claude AI
