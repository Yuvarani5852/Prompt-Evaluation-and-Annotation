# Prompt Evaluation Scoring Rubric

## Overview
This rubric is used to evaluate AI-generated responses across multiple LLM platforms (ChatGPT, Claude AI, GitHub Copilot). Each response is scored on 5 parameters, each out of 10 points. Maximum total score: 50 points.

---

## Evaluation Parameters

### 1. Accuracy (0–10)
Does the response provide factually correct and relevant information?

| Score | Description |
|-------|-------------|
| 9–10  | Completely accurate, no errors |
| 7–8   | Mostly accurate, minor errors |
| 5–6   | Partially accurate, some incorrect info |
| 3–4   | Mostly inaccurate |
| 0–2   | Completely wrong or irrelevant |

---

### 2. Relevance (0–10)
Does the response directly address the prompt without going off-topic?

| Score | Description |
|-------|-------------|
| 9–10  | Perfectly on-topic, fully addresses the prompt |
| 7–8   | Mostly relevant, minor off-topic content |
| 5–6   | Partially relevant, significant off-topic content |
| 3–4   | Mostly off-topic |
| 0–2   | Completely irrelevant |

---

### 3. Tone & Style (0–10)
Is the tone appropriate for the context (professional, casual, technical)?

| Score | Description |
|-------|-------------|
| 9–10  | Perfect tone for the context |
| 7–8   | Mostly appropriate tone |
| 5–6   | Somewhat appropriate, minor tone issues |
| 3–4   | Inappropriate tone for context |
| 0–2   | Completely wrong tone |

---

### 4. Coherence (0–10)
Is the response well-structured, logical, and easy to understand?

| Score | Description |
|-------|-------------|
| 9–10  | Perfectly structured, flows logically |
| 7–8   | Mostly coherent, minor structure issues |
| 5–6   | Somewhat coherent, some confusing parts |
| 3–4   | Mostly incoherent |
| 0–2   | Completely disorganized |

---

### 5. Completeness (0–10)
Does the response fully answer the prompt without missing key points?

| Score | Description |
|-------|-------------|
| 9–10  | Fully complete, covers all aspects |
| 7–8   | Mostly complete, minor gaps |
| 5–6   | Partially complete, missing key points |
| 3–4   | Mostly incomplete |
| 0–2   | Completely incomplete |

---

## Total Score Interpretation

| Total Score | Grade | Interpretation |
|-------------|-------|----------------|
| 45–50 | A+ | Excellent response |
| 38–44 | A  | Very good response |
| 30–37 | B  | Good response |
| 20–29 | C  | Average response |
| 10–19 | D  | Poor response |
| 0–9   | F  | Unacceptable response |

---

## How to Use This Rubric
1. Read the prompt carefully
2. Read the AI-generated response
3. Score each parameter independently
4. Sum up the total score
5. Record results in `evaluation_results.csv`
6. Add feedback/notes for improvement
